Indent with tabs, not spaces — the editor is configured to render a tab as
four columns, but the bytes on disk stay tabs so everyone can pick their own
width. Keep lines under 100 columns. Prefer explicit imports over wildcard
imports. Run the formatter on save; never hand-align assignments. These are
demo preferences, safe to delete — they exist only to show the `user` memory
kind.
